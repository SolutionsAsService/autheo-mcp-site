GOOD TO KNOW

A little more
context.

Is this a live Autheo dashboard?+

No. This site explains the MCP server and demonstrates example workflows. It never connects to your infrastructure or requests credentials. Live reads happen in your locally configured MCP server.

Can my AI deploy or buy resources?+

Not with v0.2. Registered tools are read-only or local simulations. Marketplace settlement records are inspected, not payment-verified; DevHub deployments are inspected, not created.

Which AI clients can I use?+

Use a client that supports local MCP servers over stdio. Client configuration formats vary; the Quickstart includes a common mcpServers example. Consult your client’s documentation for its exact configuration location.

How do I deploy this website?+

The frontend is static, with no runtime dependencies. Serve the frontend folder on a static host. The repository includes an opt-in GitHub Pages workflow and deployment instructions; publishing this site does not host the Python MCP server.

Read deployment instructions ↗
Where are my credentials stored?+

In your MCP server’s environment, managed locally by you or your client’s secure configuration. This website has no credential fields, analytics, or backend calls. DevHub, Marketplace, and the private bridge use separate authentication.
